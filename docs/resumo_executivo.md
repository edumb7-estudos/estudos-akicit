# Resumo Executivo

## Visão Geral

Este projeto consiste no desenvolvimento de uma Micro-API REST para gerenciamento de tarefas, utilizando FastAPI, SQLite e SQLAlchemy. A aplicação implementa operações CRUD completas, testes automatizados e documentação para facilitar sua utilização e manutenção.

## Objetivo da Análise

A análise de riscos teve como objetivo identificar possíveis fatores que poderiam comprometer o desenvolvimento, a qualidade ou a evolução da aplicação, permitindo definir estratégias preventivas para minimizar seus impactos.

## Principais Riscos

Os principais riscos identificados foram:

- Entrada de dados inválidos na API.
- Regressões após alterações no código.
- Documentação insuficiente para manutenção futura.
- Limitações do banco de dados SQLite em cenários de maior escala.

## Estratégias Adotadas

Como forma de mitigação, foram utilizados testes automatizados, validação de dados por meio do Pydantic e documentação atualizada do projeto, reduzindo a probabilidade de falhas e facilitando futuras manutenções.

## Uso da Inteligência Artificial Generativa

A Inteligência Artificial Generativa foi utilizada para apoiar a identificação de riscos, estruturar a documentação e revisar os artefatos produzidos. Todas as sugestões foram analisadas criticamente e adaptadas às necessidades do projeto antes de sua adoção.

## Conclusão

A análise de riscos contribuiu para aumentar a confiabilidade do projeto, permitindo antecipar possíveis problemas e definir ações preventivas que favorecem a qualidade, a manutenção e a evolução da aplicação.
